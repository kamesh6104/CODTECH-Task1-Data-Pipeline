ETL Data Pipeline using Pandas and Scikit-learn (CODTECH Internship Task 1)
CODTECH Internship – Task 1  
Data Pipeline using Pandas & Scikit-learn

Objective
To create an automated data pipeline for data preprocessing, transformation, and loading (ETL).

Dataset
- Inbuilt Iris dataset from Scikit-learn

Tools & Libraries
- Python
- Pandas
- Scikit-learn

Pipeline Steps
1. Extract data using Scikit-learn
2. Transform data using scaling and train-test split
3. Load processed data into CSV files
